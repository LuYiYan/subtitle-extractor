## Windows 正式版

这是 **字幕去除与繁体转换 v1.4.4** 的 Windows 正式版（CPU）。功能完整，可直接用于日常处理。

请优先下载 **`subtitle-extractor-v1.4.4-windows-cpu-setup.exe`**。

1. 双击安装程序。
2. 默认安装到 `C:\SubtitleExtractor`。可以改盘符，但路径只能是英文和数字，不能有中文或空格，例如 `E:\SubtitleExtractor`。开始菜单会加入「字幕去除器」。需要桌面图标时，在安装页勾选。
3. 打开开始菜单里的「字幕去除器」。
4. 第一次打开会先出现「正在准备运行环境，请稍候」。请等这个窗口自己关掉。之后只留下图形界面。
5. 要删除时，打开 Windows 设置里的「应用」，卸载「字幕去除与繁体转换」。

同一页上的 `.7z` 是便携包：用 [7-Zip](https://www.7-zip.org/) 解压后双击「启动程序.exe」。有 `.7z.001`、`.7z.002` 时要全部下载到同一个文件夹，再解压 `.001`。

### 这个版本包含

- 去除视频硬字幕
- 图片：右侧「导入图片」，左侧预览，框选文字后可转成台湾用语繁体，再用「保存图片」另存
- 可选：把选区里的简体硬字幕转成台湾用语繁体（OpenCC `s2twp`），导出 SRT，或把校对后的 SRT 烧回去
- 已带上：Python、CPU 版 PyTorch / Paddle、FFmpeg、Noto Sans CJK TC、去字幕模型和 PP-OCRv5 检测/识别模型

这是 CPU 版，功能完整，不依赖 NVIDIA 显卡，处理速度比显卡版慢。长视频需要更多时间。

v1.4.2 及以后的第一次准备不会再出现 v1.4.1 那种安装组件被提前结束的错误。v1.4.4 会把文字识别组件一并装好，图片和视频的「硬字幕转繁体」可以正常识别。安装目录请使用上面的英文路径。

同一发布页如果还有 `windows-directml` 或 `windows-nvidia-cuda` 压缩包，那是显卡加速正式版。没有这些文件时，请使用本页的 CPU 安装程序。

macOS 和 Linux 没有单独的桌面安装包（与上游一致）。请按 README 用源码运行，或由维护者用 Docker 工作流构建镜像。
