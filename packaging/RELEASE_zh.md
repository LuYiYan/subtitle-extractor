## Windows 正式版

这是 **字幕去除与繁体转换 v1.4.2** 的 Windows 便携正式版（CPU）。功能完整，可直接用于日常处理。解压后双击「启动程序.exe」即可，**不需要安装 Python**。

v1.4.1 在第一次准备运行环境时会失败（安装组件的 Python 进程被提前结束）。请改用本版，不要继续用 v1.4.1。

请下载本页名字里带 `windows-cpu` 的文件：

- 只有一个 `.7z`：用 [7-Zip](https://www.7-zip.org/) 解压。
- 有 `.7z.001`、`.7z.002` ……：全部下载到同一个文件夹，右键 `.001`，用 7-Zip 解压。少一个分卷就解不开。

第一次双击「启动程序.exe」时，会先出现「正在准备运行环境，请稍候」。请等这个窗口自己关掉。准备完成后只留下「字幕去除器」。之后再打开，直接进入图形界面，不会留下命令行窗口。

压缩包里的「使用说明.txt」写了视频去字幕、简体转繁体，以及图片导入、预览和保存。

### 这个版本包含

- 去除视频硬字幕
- 图片：右侧「导入图片」，左侧预览，框选文字后可转成台湾用语繁体，再用「保存图片」另存
- 可选：把选区里的简体硬字幕转成台湾用语繁体（OpenCC `s2twp`），导出 SRT，或把校对后的 SRT 烧回去
- 已打包：Python、CPU 版 PyTorch / Paddle、FFmpeg、Noto Sans CJK TC、去字幕模型和 PP-OCRv5 检测/识别模型

这是 CPU 版，功能与显卡版相同，不依赖 NVIDIA 显卡，处理速度比显卡版慢。长视频需要更多时间。

同一发布页如果还有 `windows-directml` 或 `windows-nvidia-cuda` 压缩包，那是显卡加速正式版，安装方式相同。没有这些文件时，请使用 `windows-cpu`。

macOS 和 Linux 没有单独的桌面安装包（与上游一致）。请按 README 用源码运行，或由维护者用 Docker 工作流构建镜像。
