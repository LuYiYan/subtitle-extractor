## 给要试用的人

这是 **Windows 便携版（CPU）v1.4.1**。解压后双击「启动程序.exe」即可，**不需要安装 Python**。第一次打开会短暂出现准备窗口，随后只留下图形界面；之后再打开不会留下命令行窗口。

请下载本页名字里带 `windows-cpu` 的 v1.4.1 文件：

- 只有一个 `.7z`：用 [7-Zip](https://www.7-zip.org/) 解压。
- 有 `.7z.001`、`.7z.002` ……：全部下载到同一个文件夹，右键 `.001`，用 7-Zip 解压。少一个分卷就解不开。

压缩包里的「使用说明.txt」有打开方法，以及怎么试视频去字幕、简体转繁体、图片转繁体。

### 这个版本包含

- 去除视频硬字幕，或打开图片：右侧「导入图片」，左侧预览，框选文字后转成台湾用语繁体，再用「保存图片」另存
- 可选：把选区里的简体硬字幕转成台湾用语繁体（OpenCC `s2twp`），导出 SRT，或把校对后的 SRT 烧回去
- 已打包：Python、CPU 版 PyTorch / Paddle、FFmpeg、Noto Sans CJK TC、去字幕模型和 PP-OCRv5 检测/识别模型

CPU 版不挑显卡，速度比显卡版慢。请先用短视频或一张图片。

同一发布页如果还有 `windows-directml` 或 `windows-nvidia-cuda` 压缩包，那是显卡加速版，安装方式相同。普通试用请用 `windows-cpu`。

macOS 和 Linux 没有单独的桌面安装包（与上游一致）。请按 README 用源码运行，或由维护者用 Docker 工作流构建镜像。
