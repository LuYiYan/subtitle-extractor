字幕去除与繁体转换
Windows 便携版（CPU）

这个文件夹已经带好 Python、去字幕模型、繁体转换、字体和 FFmpeg。
不需要再安装 Python，也不需要配置环境变量。

一、怎么打开
1. 如果下载到的是好几个文件（名字以 .7z.001、.7z.002 结尾），请全部放在同一个文件夹里。只下载其中一个是解压不了的。
2. 安装 7-Zip：https://www.7-zip.org/
   只有一个 .7z 文件时，也可以用 7-Zip 打开。
3. 右键第一个分卷（.7z.001；如果只有一个 .7z，就右键它）→ 7-Zip → 解压到当前文件夹。
4. 进入解压出来的文件夹，先看本说明，然后双击「启动程序.exe」。
5. 第一次打开会多出一个标题为「正在准备运行环境，请稍候」的窗口。请等它自己关掉。准备好之后只留下「字幕去除器」。这个程序窗口不挂在黑色命令行上，关掉别的命令行窗口不会把软件关掉。
6. 以后再打开，直接就是「字幕去除器」，不会再留一个命令行窗口。

二、处理视频
1. 点「打开」，选一个较短的 mp4（建议先用一两分钟的视频）。
2. 在预览画面上框住底部字幕。可以多框几条。
3. 只想擦掉硬字幕：不要打开「硬字幕转繁体」，直接点「运行」。
4. 想把画面上的简体字换成台湾用语繁体：打开「硬字幕转繁体」，再点「运行」。
   程序会识别框里的字，擦掉原字，再按原来的位置和大约的颜色写上繁体。
5. 还想要一个字幕文件：打开「导出繁体 SRT」。完成后，SRT 和视频在一起。
6. 校对过 SRT、想把校对稿烧回画面：到下方「设置」里的「繁体字幕」，选中那份 SRT，打开「烧录修正后的 SRT」，再运行。
7. 完成后，结果视频默认在原视频旁边。任务列表里可以「打开目标视频位置」。

三、处理图片
1. 点右侧蓝色的「导入图片」，选 jpg、png、webp、bmp。左侧会马上显示这张图。
2. 用鼠标在图上框住要转换的文字。
3. 打开「硬字幕转繁体」，点「运行」。程序会识别文字、擦掉，再画成繁体。图片自动使用 LAMA。
4. 完成后，预览左边是原图，右边是转换结果。看清楚后再点「保存图片」，选保存位置，就可以把图发给客户。
5. 只想去掉图片上的字、不重写：不要打开「硬字幕转繁体」，运行后再点「保存图片」。

四、这个包里已经有的
- 去字幕：STTN 智能擦除、STTN 字幕检测、LAMA、ProPainter、OpenCV
- 简体转台湾用语繁体（OpenCC s2twp）、导出 SRT、烧录校对稿
- 文字检测模型，以及文字识别模型 PP-OCRv5_server_rec
- 字体 Noto Sans CJK TC
- Windows 版 FFmpeg（用来把原音轨拷回去）
- CPU 版 PyTorch 和 Paddle。没有 NVIDIA 显卡也能用

五、什么时候还要联网
- 正常的发布包已经带上识别模型，转繁体时不用再下载。
- 如果有人自己打包时跳过了下载，第一次转繁体时 PaddleOCR 会联网下载 PP-OCRv5_server_rec。
- 启动时如果打开了「检查更新」，会访问 GitHub。不影响处理视频。

六、请注意
- 这是功能完整的 CPU 正式版，Windows 10 / 11 可直接日常使用。处理速度比显卡版慢，长视频需要更多时间。
- 第一次打开时的准备窗口请等它自己结束。准备完成后没有需要一直留着的命令行窗口。
- 解压或第一次打开需要几 GB 空闲磁盘。
- 转繁体的目标是台湾用语繁体，不是任意外语翻译。英文和数字会保持原样。
